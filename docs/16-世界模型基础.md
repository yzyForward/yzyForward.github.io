# 世界模型基础：状态 + Action → 下一状态

> 元境智能座舱大模型落地实战系列第 16 篇，补充篇。面试如果被问到"世界模型"，能讲清状态转移和 action 来源就够了。这篇讲核心概念，不写进简历、面试备用。

---

## 一、世界模型是什么

一句话：**输入当前状态 + action，输出下一状态。**

```
(当前状态, action) → 世界模型 → 下一状态
```

比如座舱里：

- 当前状态：空调 22 度；action：调高 1 度 → 下一状态：空调 23 度。
- 当前状态：车窗关闭；action：打开 → 下一状态：车窗开启。

世界模型就是"环境怎么响应动作"的预测器。有了它，系统就能"在脑子里推演"——执行某个动作后，状态会变成什么样，从而做规划。

## 二、action 从哪来（面试常问）

action 有**三种来源**：

1. **规则策略**：写死的 if-else。比如"检测到疲劳 → 提醒休息"。确定、可预测，但覆盖不了复杂情况。
2. **强化学习策略（RL）**：通过奖励信号学出来的策略，能处理复杂决策，但训练成本高、可解释性差。
3. **大模型规划（LLM）**：用大模型做高层规划，灵活、通用，但延迟高、可能有不确定性。

量产里通常是**混合用**：**规则兜底 + RL 决策 + LLM 高层规划**。

- 规则管安全底线（疲劳必提醒、危险操作拦截）；
- RL 管高频决策（什么时候推主动服务）；
- LLM 管复杂高层意图（"回家路上帮我开空调"这种跨域规划）。

## 三、座舱里哪些是 action

座舱里的 action 很丰富，都能抽象成"动作"：

- 车控：空调开关/调温、车窗升降、座椅调节、氛围灯；
- 娱乐：切歌、调音量、播放/暂停；
- 导航：设置目的地、改路线；
- 主动服务：提醒休息、推荐音乐、推送到家开空调。

每个 action 都对应一个"状态转移"——执行后环境变成什么样。

## 四、核心代码示意

```python
class WorldModel:
    """世界模型：预测 (状态, action) 的下一个状态"""
    def step(self, state, action):
        # action 来自规则 / RL / LLM 规划
        next_state = dict(state)
        if action["type"] == "set_temperature":
            next_state["ac_temp"] = action["value"]
        elif action["type"] == "open_window":
            next_state["window"] = "open"
        elif action["type"] == "play_music":
            next_state["music"] = "playing"
        return next_state

# 三种 action 来源的混合
def choose_action(state):
    if rule_action(state):          # ① 规则兜底（安全底线）
        return rule_action(state)
    if rl_action(state) is not None:  # ② RL 决策（高频）
        return rl_action(state)
    return llm_plan(state)          # ③ LLM 高层规划（复杂跨域）
```

关键：世界模型管"状态怎么变"，action 来源管"这一步做什么"。面试讲清这两点就够了。
