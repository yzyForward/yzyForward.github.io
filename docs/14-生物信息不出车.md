# 生物信息不出车：多模态座舱的合规底线和架构设计

> 元境智能座舱大模型落地实战系列第 14 篇。多模态座舱要处理人脸、语音、情绪这些敏感数据，稍不注意就踩合规红线。这篇讲"生物信息不出车"这条底线的来龙去脉，以及它怎么反过来影响架构。

---

## 一、问题：多模态处理的是"生物信息"

座舱多模态要识别疲劳、情绪、乘员，这背后处理的是：

- **人脸**（谁上车、什么表情）
- **语音**（说了什么、什么语气）
- **行为状态**（疲劳、分心、情绪）

这些都属于**生物识别信息**，是敏感个人信息里最敏感的一类。

## 二、法规的硬要求：生物信息不得出车

汽车数据安全管理规定里，对生物识别信息有明确要求：

- **默认不采集**，采集需**单独同意**；
- **不得出车**（除非确有必要且脱敏）；
- 车内处理，最小化采集。

所以"把疲劳检测放云端"这种方案，技术上能做，但**合规上直接淘汰**——生物信息一旦回传云端，就踩红线了。

## 三、架构上的应对：生物信息全放端侧

合规约束反过来决定了架构：

- **生物信息相关的模型全放端侧**（车机芯片）：人脸、情绪、驾驶员状态这些，端侧本地处理，**数据不出车**；
- **云端只承担非敏感**的多轮推理、主动服务决策。

这样既满足合规，还顺带拿到了**低延迟**（本地推理不用等网络）——合规和工程收益是一体的，不是"为了合规牺牲性能"。

## 四、"不出车"的落地细节

"生物信息不出车"落到工程上，要做几件事：

1. **端侧本地处理**：模型在车机芯片上跑，原始人脸、语音不上云；
2. **最小化采集**：只采集业务必需的最小数据，能不用就不用；
3. **不长期落盘**：敏感数据用完即弃，不做长期存储；
4. **脱敏**：确需外传的非敏感信息，做脱敏处理。

核心原则：**让数据用得上，但认不出人、出不了车。**

### 找物品场景的人脸脱敏流程

找物品这个功能很典型：既要"看懂画面里有什么物品"，又不能把"人脸"传上去。我的做法是四步：

1. 端侧 Qwen2.5-Omni-7B 检测到人脸；
2. 对帧内**人脸区域做高斯模糊或马赛克**；
3. 确认**无生物特征**后**加密上传**非敏感帧；
4. 云端 Qwen3-VL 做开放词汇物品识别。

为什么用模糊而不是丢弃？因为找物品场景必须保留物品信息——**人脸可以模糊、物品必须清楚**。

## 五、这是"技术 + 合规"的双加分项

面试或写博客，这一点要能讲透：

> 不是"技术上不能上云"，而是"**法规要求生物信息不出车 + 端侧处理还更快**"，把合规约束和工程收益一起讲。

很多工程师只会说"为了合规所以放端侧"，显得被动；真正好的表述是"**端侧处理既合规、又更快，一举两得**"。

## 六、端侧模型更新也要走合规通道

还有个容易被忽略的点：端侧模型更新（OTA）也要合规。模型本身就涉及数据，更新要：

- 走灰度 + 版本化 + 回滚；
- 更新过程留痕可审计。

合规不只是"数据不出车"这一件事，而是贯穿采集、处理、更新、删除的全生命周期。

## 七、总结

可复用的三条：

1. 人脸、语音、情绪是**生物识别信息**，法规要求**不得出车**。
2. 架构上**生物信息全放端侧、云端只做非敏感**，合规和低延迟一举两得。
3. 合规是**全生命周期**的：采集最小化、端侧处理、不落盘、更新留痕。

```python
# 生物信息相关模型只注册到端侧，云端不允许部署

def deploy(model_name: str):
    # 部署前置校验：生物信息模型禁止上云
    assert model_name in EDGE_ONLY_MODELS, \
        f"生物信息模型 {model_name} 不允许部署到云端"
    return edge_deploy(model_name)   # 只在车机芯片本地跑

def blur_faces(frame):
    """人脸高斯模糊：找物品场景保留物品信息、抹掉人脸"""
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    faces = face_cascade.detectMultiScale(gray, 1.1, 5)
    for (x, y, w, h) in faces:
        frame[y:y+h, x:x+w] = cv2.GaussianBlur(frame[y:y+h, x:x+w], (51, 51), 30)
    return frame

def upload_if_clean(frame, trace_id):
    """确认无生物特征后加密上传；含未脱敏人脸则拒绝外传"""
    if has_unblurred_face(frame):
        return None   # 拒绝外传，端侧重跑脱敏
    payload = cv2.imencode(".jpg", frame)[1].tobytes()
    return cloud_storage.upload(f"{trace_id}/frame.jpg", encrypt(payload))
```
