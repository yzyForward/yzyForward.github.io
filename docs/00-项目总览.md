## 一、项目背景：车企为什么需要大模型座舱

传统语音座舱只能听懂固定几句指令——"打开空调""导航到某地"。用户换个说法它就听不懂，更别提理解"我有点累""帮我找下那个东西"这类真实意图了。

大模型出现后，座舱有了质变的可能：

1. **自由对话**：从固定指令到自然语言理解，想怎么说就怎么说。
2. **跨域办事**：一句话"回家路上帮我开空调"能串联导航、车控、车家互联多个能力。
3. **看懂状态**：加了视觉后，疲劳、分心、儿童遗忘这些"用户不会自己说"的状态也能被感知，做主动服务。

我们的目标就是：**把座舱从"听懂指令"推进到"看懂状态、主动办事"**。

## 二、三个项目一条线（项目情况）

这个项目不是一口气做完的，而是三个项目递进，一条线串起来：

| 阶段 | 项目 | 时间 | 解决什么 |
|------|------|------|---------|
| 1 | **知识底座（RAG）** | 2024.06–2024.11 | 把座舱知识结构化，让答案"有据可查" |
| 2 | **中枢平台（多智能体）** | 2024.12–2025.10 | 用"1 中枢 + N 领域"让车"会办事" |
| 3 | **多模态升级** | 2025.09–2026.09 | 加视觉，让车"看懂状态" |

**逻辑关系**：先有知识（能查）→ 再有编排（能办事）→ 最后加感知（能看懂）。三个项目是从下到上、从内到外的演进。

- **知识底座**：给上层多智能体提供带出处的检索，是"知识层"。
- **中枢平台**：多智能体编排，是"编排层"，它把知识底座封装成知识检索 Agent 接入。
- **多模态升级**：在编排骨架上加视觉这条感知线，复用原有的调度、仲裁、主动服务机制。

## 三、技术选型（为什么是这一套）

选型总原则：**能私有化、和生态一致、按端云分工选尺寸**。

### 基座模型：千问生态一路用下来

| 位置 | 模型 | 干什么 | 为什么 |
|------|------|--------|--------|
| 端侧（车机芯片） | **Qwen2.5-Omni-7B**（INT8 量化 + 蒸馏） | 唤醒、轻量意图分类、视觉实时初筛、人脸脱敏 | 原生多模态（文本/图像/音频），7B 量化后塞得进车机，生物信息本地闭环 |
| 云端（GPU） | **Qwen3-VL** | 非敏感视觉：找物品、车外环境理解 | 视觉理解 + 推理一体 |
| 云端（GPU） | **文本 LLM**（Qwen2.5/Qwen3） | 疲劳/分心复核、多模态融合决策 | 端侧已输出结构化特征，云端不用再看原始图像 |

> 为什么一路用千问？从中行的 Qwen1.5 试点，到车企的 Qwen2、Qwen2.5、Qwen2.5-Omni、Qwen3-VL，生态一路用下来，tokenizer、部署栈、调优经验都能复用，上手快。

### 其它关键选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 向量库 | Milvus | 开源可私有化、支持混合检索 + 过滤下推 |
| 图数据库 | Neo4j | 存"场景—意图—技能—服务卡片"多跳关系 |
| Embedding | BGE-M3 | 稠密 + 稀疏一体、多语言、可私有化 |
| 编排 | LangGraph + LangChain + LlamaIndex | 流程/工具/检索分层 |
| Agent 协议 | MCP + A2A | MCP 管工具调用、A2A 管 Agent 间委派 |
| 云端推理 | vLLM | PagedAttention 管显存、连续批处理提吞吐 |
| 端侧推理 | ONNX Runtime / TensorRT | INT8 量化 + NPU 加速 |
| 评测 | Langfuse | 开源可私有化、链路追踪 + 评测回归 |

## 四、技术方案：整体架构

整体分五层：

```
┌────────────── 接入层 ──────────────┐
│  语音 / 摄像头 / 手势（多模态输入）  │
└───────────────────────────────────┘
          │
┌────────────── 感知层 ──────────────┐
│ 端侧 Qwen2.5-Omni-7B（唤醒/意图/   │
│  视觉初筛/人脸脱敏，150ms 内）      │
└───────────────────────────────────┘
          │ 结构化特征 + 脱敏非敏感帧
┌────────────── 编排层 ──────────────┐
│  MasterAgent（意图理解/任务分解/    │
│  路由）+ N 个领域 Agent            │
└───────────────────────────────────┘
          │
┌────────────── 知识层 ──────────────┐
│  RAG 知识底座 + 知识图谱 + 记忆      │
└───────────────────────────────────┘
          │
┌────────────── 治理层 ──────────────┐
│  版本/权限/缓存/评测/数据飞轮/人在回路│
└───────────────────────────────────┘
```

### 端云协同（核心设计）

按"**低延迟 + 隐私 → 端侧，复杂推理 → 云端**"切分：

- **端侧**：唤醒、轻量意图分类、视觉实时初筛、人脸脱敏——生物信息不出车。
- **云端**：非敏感视觉（找物品）、多轮推理、融合决策。

数据流：**端侧结构化特征 + 脱敏非敏感帧 → 云端**。原始人脸、语音不出车。

### 数据飞轮

```
Kafka 采集日志 → 接管率挖 Bad Case → 人工复核
  → 定向采样 + 数据增强 → LoRA 微调小模型 + Prompt 优化大模型
  → Langfuse 评测回归 → 灰度上线 → 再采集
```

让模型越用越准，疲劳误报率从 8% 降到 3% 就是靠这个闭环。

## 五、核心代码：端云协同的骨架

```python
"""端云协同核心骨架（脱敏示意代码）"""
from __future__ import annotations
import logging, hashlib, time
from dataclasses import dataclass, field
from typing import Optional
import numpy as np
import cv2  # 端侧人脸检测与模糊

logger = logging.getLogger("cockpit.ai")

# ── 任务分流配置 ──────────────────────────────
EDGE_TASKS = {"唤醒", "意图分类", "疲劳初筛", "人脸脱敏", "手势识别"}
CLOUD_TASKS = {"找物品", "车外理解", "多轮推理", "融合决策"}
EDGE_LATENCY_BUDGET_MS = 150  # 端侧延迟预算

# ── 数据结构 ──────────────────────────────────
@dataclass
class EdgeResult:
    task: str
    state: Optional[str] = None          # 疲劳/分心/正常
    confidence: float = 0.0
    features: dict = field(default_factory=dict)  # 结构化特征（非原始图像）
    frame: Optional[np.ndarray] = None   # 脱敏后的帧
    latency_ms: float = 0.0

@dataclass
class Task:
    type: str
    payload: dict = field(default_factory=dict)
    trace_id: str = ""

# ── 端侧模型封装 ──────────────────────────────
class EdgeOmniModel:
    """端侧 Qwen2.5-Omni-7B：文本/图像/音频统一入口"""
    def __init__(self, model_path: str, backend: str = "onnx"):
        self.session = load_onnx_session(model_path, backend)  # 挂 NPU

    def infer(self, task: str, frame=None, audio=None) -> EdgeResult:
        t0 = time.perf_counter()
        inputs = self._build_inputs(task, frame, audio)
        raw = self.session.run(None, inputs)
        result = self._parse(task, raw)
        result.latency_ms = (time.perf_counter() - t0) * 1000
        assert result.latency_ms <= EDGE_LATENCY_BUDGET_MS, "端侧超预算"
        return result

# ── 人脸脱敏 ──────────────────────────────────
def blur_faces(frame: np.ndarray) -> np.ndarray:
    """高斯模糊人脸区域，确认无生物特征后返回"""
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    faces = face_cascade.detectMultiScale(gray, 1.1, 5)
    for (x, y, w, h) in faces:
        roi = frame[y:y+h, x:x+w]
        roi = cv2.GaussianBlur(roi, (51, 51), 30)   # 强模糊，不可逆
        frame[y:y+h, x:x+w] = roi
    return frame

def encrypt_and_upload(frame: np.ndarray, trace_id: str) -> str:
    """加密上传非敏感帧（人脸已脱敏）"""
    payload = cv2.imencode(".jpg", frame)[1].tobytes()
    digest = hashlib.sha256(payload).hexdigest()[:16]
    return cloud_storage.upload(f"{trace_id}/{digest}.jpg", encrypt(payload))

# ── 云端调用封装 ──────────────────────────────
def cloud_invoke(task: str, payload: dict, retry: int = 3):
    """云端调用：重试 + 超时 + 熔断兜底"""
    for i in range(retry):
        try:
            return cloud_client.call(task, payload, timeout=2.0)
        except TimeoutError:
            logger.warning(f"云端超时，第 {i+1} 次重试")
    return fallback(task)   # 云端不可用，端侧兜底

# ── 端云分流主逻辑 ────────────────────────────
def dispatch(task: Task):
    if task.type in EDGE_TASKS:
        result = edge_model.infer(task.type, **task.payload)
        if "face" in result.features:
            result.frame = blur_faces(task.payload["frame"])    # 先脱敏
            task.payload["frame_url"] = encrypt_and_upload(
                result.frame, task.trace_id)
        return result
    # 云端任务：只碰非敏感数据
    return cloud_invoke(task.type, task.payload)
```

这段骨架把端云协同的关键工程点都串起来了：**任务分流配置、端侧延迟预算断言、人脸高斯模糊脱敏、加密上传、云端重试熔断**——代码是脱敏示意，但每一层都对应真实生产里会踩的坑。
